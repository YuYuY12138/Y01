- 日期：2026-10-15；状态：用户已批准（方案A终版）。
- 需求来源：`玩法策划摘要.md` 第34节（1749—1803行）与R37接收入口（821—827行）。

## 0. 总体结构
| 职责 | 承载 | 说明 |
| --- | --- | --- |
| 百分比、三维链、条件、金币获取% | 自写 `FY01AttributeResolver` | 输出最终值与“百分比前小计”供来源明细 |
| 暴击率、暴击倍率、吸血% | `UY01AttributeSet` 新属性 | 沿用护甲/生命回复模式：结算器算出后写base，随来源事务提交/回滚 |
| 护盾 | 新服务器组件（玩家） | 按来源分层，唯一真源；仅复制总量供血条 |
| 伤害结算 | 共享纯函数 | 三个执行器（`UY01DamageExecution`、`UY01TemplateDamageExecution`、测试技能执行器）各自前置不变，统一调用 |

不把百分比/条件改成GE乘法修饰或Tag要求：三维须在换算前放大、来源明细需要百分比前小计，GAS聚合器不提供；且项目已有多来源Additive GE回滚浮点偏差的前例。

## 1. 第一期：百分比与生命条件
### 配表
- `EY01SourceEffectKind` 新增 `AttributePercent`。
- `EY01Attribute` 新增 `GoldGain`（金币获取）。
- `AttributePercent` 可作用：力量、敏捷、智力、攻击、生命上限、攻击频率、护甲、生命回复、金币获取。`GoldPerSecond` 目标报错。
- `Amount` 填 `20` 表示 +20%；首版只允许非负，内部保留小数，显示沿用现有方式。
- `FY01SourceEffectRow` 新增 `Condition`（None / HealthBelow / HealthAbove）与 `ConditionThreshold`（0—100，百分数）。

### 计算
- 有效三维 = (基础 + 固定 + 成长) × (1 + 三维%)。
- 衍生小计 = 基础 + 固定 + 成长 + Σ 有效三维 × 系数（含条件固定值）。
- 衍生最终 = 小计 × (1 + 该属性%)。同属性来源相加，不连乘。
- 攻击频率：次数/秒小计 × (1 + %)，再取倒数为攻击间隔。
- 攻击统一：固定攻击（`AttackFlat`）与装备成长攻击并入结算器小计，结算器输出最终攻击，仅写一条派生攻击GE；替换原逐来源攻击GE，使百分比覆盖全部攻击来源。
- 金币获取%无基础值，最终值即百分比合计，供第四期消费。

### 生命条件
- 仅可挂在 `AttributeFlat` / `AttributePercent` 上，且目标只能为攻击、护甲、生命回复、攻击频率、金币获取。
- 禁止作用于生命上限与三维（三维可经换算间接改变生命上限，导致阈值振荡）。
- 生命比例 = 当前生命 / 当前生命上限，不计护盾；低于为严格 `<`，高于为严格 `>`。
- DS在 Health / MaxHealth 变化时判定；仅当条件状态翻转时触发重新结算并走既有来源事务提交。

### 来源明细
- 每个属性给出：最终值、百分比前小计、百分比合计、各来源贡献（固定/百分比/系数/成长），条件效果标注当前是否生效。
- 本期接入测试UI文本；正式UI按COLLAB-03交UI窗口。

## 2. 第二期：暴击、吸血、护盾
### 暴击
- 新来源效果：`CritChance`（Amount为百分数，合计封顶100%）、`CritMultiplierAdd`（在默认倍率上相加）。
- 默认暴击倍率 2.0，配置于 `DT_MatchRules`。
- 判定时机：直接命中在取伤害快照时；飞行物在发射时；DOT在施加时判一次，后续每跳沿用；持续区域伤害按DOT处理，在放置时判一次。
- 暴击结果随快照传入结算（SetByCaller或授权记录），`FY01DamageEvent` 增加暴击标记，展示配置增加暴击颜色。

### 共享伤害函数
- 顺序：快照基础 → ×暴击倍率（若暴击）→ 减护甲（下限0）→ 护盾吸收 → 扣生命（不超过当前生命）→ 吸血。
- 红色飘字显示扣甲后数值（与现口径一致）。
- 击杀奖励、成长、吸血均按实际生命损失；护盾吸收部分不计。
- 怪物对玩家的伤害同样先被护盾吸收。

### 吸血
- 新来源效果 `Lifesteal`（Amount为百分数）。
- 恢复 = 实际生命损失 × 吸血%，不超过生命上限，以绿色治疗飘字逐次显示；不能回复护盾。
- 伤害效果新增“可吸血”开关：普攻、主动技能默认开，DOT默认关。

### 护盾
- 新来源效果：`ShieldPeriodic`（任意来源，按间隔获得）、`ShieldOnCast`（仅技能来源，释放该技能时获得）；字段含数值、持续时间、本层上限、间隔。
- 首版只用固定值，不做属性换算。
- 按来源分层；同来源再次获得：在剩余值上累加至本层上限，并刷新持续时间；不同来源独立相加。
- 受伤先扣最快到期层。死亡、复活、离局清空全部层。
- 不计入生命条件，不被吸血回复。
- 组件复制护盾总量，玩家血条显示。

## 3. 第三期：时间成长与普攻成长
- `EY01GrowthTrigger` 新增 `CombatTime`、`BasicAttack`；成长属性仍为攻击、力量；对象沿用装备实例/玩家（32.5节）。
- 时间成长：主线进入战斗阶段且来源生效即计时；死亡等待与练功房均不暂停（用户改写第34节原文“死亡等待不计时”）；卸下装备暂停该件计时并保留已得；本局结束停止。DS每秒结算，增长 = 经过秒数 × 每秒成长，保留小数。
- 普攻成长：普攻真正打出（近战判定执行或飞行物发射）计一次；按次数不按命中人数；下次攻击生效。
- 死亡不清空、不扣减成长；合成产物不继承材料成长。
- 成长计入百分比前小计，被对应属性%放大。

## 4. 第四期：金币获取%与主线怪均分
- 自然收入：每秒收入 × (1 + 金币获取%)。
- 主线怪：读取 `DT_Monster.Gold`，在怪物有效击杀后由死亡时在局的全部玩家均分（含死亡等待、练功房；不含断线，重连后不补发）；每人 = 份额 × 各自 (1 + 金币获取%)；击杀者无额外份。该列此前主线未发放，接入后正式生效。
- 清波奖励：每人全额 × 各自 (1 + 金币获取%)。
- 练功房：按本人或击杀者归属 × 自身 (1 + %)。金币副本暂不存在，仅登记规则。
- 每个玩家一个小数余额，满1入账。
- 其他金币入口（如失守结清）本轮保持原样。
